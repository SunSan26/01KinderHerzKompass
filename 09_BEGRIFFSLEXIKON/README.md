# Begriffslexikon

Zentrale Begriffe: GeWAHRsein, Würde, Leben, Beziehung, Freiheit, Grenze, Verantwortung, Liebe, Erkenntnis, Entwicklung, Wahrnehmung, Gefühl, Interpretation, Annahme, Tatsache, Bewusstsein, Entscheidung.

Das Lexikon dient der begrifflichen Präzision und verhindert vorschnelle Gleichsetzungen.
