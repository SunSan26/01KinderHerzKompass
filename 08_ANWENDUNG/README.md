# HERZkompass

## Offener Orientierungsrahmen für bewusstes Leben

Der HERZkompass unterstützt Menschen dabei, bewusster wahrzunehmen, zu unterscheiden, zu verstehen und eigenständig zu entscheiden.

Er ist keine Religion, Ideologie, Lehre oder verbindliches Glaubenssystem und beansprucht kein Wahrheitsmonopol.

## Repository-Prinzip

**Grundlagen → Konstruktion → Prüfung → Entscheidung → Anwendung**

Historisches Arbeitsmaterial wird vom aktuellen Projektstand getrennt.
