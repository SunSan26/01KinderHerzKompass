# Anwendung

Ablage für die Schritte 2–6 der „Nächsten Phase“ aus `00_PROJEKTSTATUS.md`:
praktische Anwendung, Produktentwicklung, technische Umsetzung, externe Prüfung,
Veröffentlichung.

## Aufnahme

Der gesetzte Weg ist Grundlagen → Konstruktion → Prüfung → Entscheidung →
Anwendung (→ `README.md`, Repository-Prinzip). Anwendungsmaterial steht am Ende
dieses Wegs.

*Offen und nicht entschieden:* ob hier ausschließlich Geprüftes aufgenommen
wird, und ob Anwendungsfragen die Grundkonstruktion öffnen dürfen. Beides ist in
den Grundlagen nicht geregelt; zur zweiten Frage siehe `00_ARBEITSMODUS.md`
Abschnitt 6, Marker `*Offen*`.
